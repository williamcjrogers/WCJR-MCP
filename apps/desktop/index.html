Desktop Commander

Desktop Commander gives the assistant Windows desktop actions such as launching apps, reading/writing clipboard, opening Explorer, and checking running processes.

If you have the separate Lookeen MCP binary such as ...\Desktop\mcp.exe, add it under Custom MCP Server instead of here.

Autonomy / Policy

Control when the assistant may act without confirmation: Observe (read-only), Assist (confirm all actions), Scoped Autonomy, or High Autonomy.

MCP Tools

Connect local and remote tools here. Start with Local Filesystem to let the assistant inspect files under a chosen folder.

Local Filesystem

Add one or more folders or drive roots the assistant can inspect. Type paths like C:\ or D:\Projects, or browse for folders.

Documents & Reports

Output folder for generated Markdown, reports, CSV, and XLSX. The assistant can write_markdown, write_report, export_csv, export_xlsx here.

Browser / Web fetch

Fetch web page content when no native API exists. Does not run JavaScript.

Desktop Commander

Launch desktop apps, inspect running processes, use clipboard, open Explorer paths, and expose Lookeen through a configured app alias.

Persistent Memory

Searches and stores long-term preferences, profile facts, and recurring instructions across conversations.

File organization

Move, rename, create folders, propose organization plans, and archive across one or more selected locations. Uses dry-run by default; confirm before applying.

Mail & Calendar (Microsoft 365)

Read inbox, draft replies, send email, list and create calendar events. Sign in with device code once; then enable the server.

Custom MCP Server

Add stdio or streamable HTTP MCP servers without leaving the app. For Lookeen MCP, use stdio and point the command to mcp.exe.
