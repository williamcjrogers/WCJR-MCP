# Using superpowers

When this skill is active, follow the core sequence every time:

1. **Before any creative work** — invoke `brainstorming` to probe intent, constraints, and trade-offs.
2. **Before any code change** — invoke `writing-plans` to produce a bite-sized plan.
3. **Before proposing any fix to a bug** — invoke `systematic-debugging` to gather runtime evidence.
4. **Before claiming anything is done** — invoke `verification-before-completion` to confirm with real output.

Red flags that mean "stop and run a sub-skill":

- "This is just a quick change."
- "I'll just try this first."
- "It should work."
- "Tests probably pass."

The discipline exists because uninvoked skills turn into fabricated confidence. Use them.
